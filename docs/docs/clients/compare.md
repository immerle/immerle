# Compare clients

|                                                | Immerle app                              | `iml`                                                          | Subsonic client                             |
| ---------------------------------------------- | ----------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------- |
| Platforms                                     | Web, iOS, Android, macOS, Windows, Linux  | macOS, Linux, Windows (terminal)                                  | Whatever the client supports                   |
| On-demand catalog, Jam, federation, discovery | Yes                                        | No, search and playback only                                     | No                                              |
| Multi-device sync / cast to device            | Yes                                        | No                                                                | No                                              |
| Resource use                                  | A normal GUI app                          | Near zero, it's just text in a terminal                          | A normal GUI app                                |
| Install                                       | Web needs nothing; desktop/mobile is a download | A single ~3 MB binary                                       | Whatever the client's own installer is          |
| Best for                                      | Everyday full-featured use                | Background music that doesn't compete with a game for RAM/CPU    | Keeping a Subsonic client you already use       |

See [Connecting clients](./index.md) for what each one is, and
[Choosing a client](../get-started/choosing-a-client.md) for install links
per platform.
